# Учебный кабинет для браузерных исполнителей

Шестнадцать типовых браузерных дел на одном статическом сайте: регистрация,
вход, поиск по базе знаний со скрытой кнопкой, фильтр каталога, выпадающий
список, поле даты, оформление заказа в три шага, отклик на заказ, карточка
услуги, настройки с переключателями, отмена заказа с подтверждением, каталог
с постраничным выводом, город из подсказок, вкладки, удаление черновика,
чтение статуса заказа.

Страница сама записывает, что пользователь на самом деле сделал, и кладёт
журнал в HTML блоком `<script type="application/json" id="stend-journal">`.
Итог проверяется по нему, а не по словам исполнителя. Журнал живёт в
`localStorage` браузера: данные никуда не отправляются.

Адрес: https://autopasha.github.io/brauzer-stend/

Сборка страниц: `python3 build.py` (пароль страницы входа задаётся хэшем в
`STEND_PASS_HASH`).
